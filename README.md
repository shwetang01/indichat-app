# Chat App Backend

A full-featured **chat application backend** built from scratch using Node.js. It supports user authentication, real-time messaging, and basic user status management.

---

## Features

- **User Registration & Login**
  - Supports phone and email OTP authentication
- **JWT Token-Based Authentication**
  - Secure login sessions using JWT
  - Uses secure cookies for enhanced security
- **Real-Time Communication**
  - Built with **Socket.IO**
  - Supports instant messaging between users
- **User Status**
  - Online/offline status
  - Basic "last seen" tracking

---

## Tech Stack

- Node.js
- Express.js
- MongoDB (or your preferred database)
- Socket.IO
- JWT for authentication
- bcrypt for password/OTP hashing
